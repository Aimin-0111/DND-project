2. Mots animés

Six effets proposés. Le scénariste choisit quels mots déclenchent quel effet.

brûlerfeu gelerglace éclairfoudre poisonmalédiction murmurepeur sacrémagie flammeslettre par lettre

Qui décide quels mots s'animent ?

Option A : l'IA marque les mots

Ce que l'IA écrit :

La [burn]torche[/burn] vacille. Votre souffle devient [freeze]brume[/freeze].

Ce que le joueur voit :

La torche vacille. Votre souffle devient brume.
  • Précis : l'IA sait que la torche est en feu.
  • Mais l'IA oublie souvent : au test, elle n'a marqué aucun mot.

Option B : une liste de mots

La liste, remplie par le scénariste :

feu : feu | flamme | brûle | braise
glace : glace | givre | gelé | froid

Ce que le joueur voit :

Vous brûlez la lettre. Il a brûlé ses vaisseaux.
  • Gratuit, régulier, contrôlé par le scénariste.
  • Mais anime aussi les images (« brûler ses vaisseaux »).
  • Il faut lister chaque forme du mot.

Option C : les deux Proposé

Les mots marqués par l'IA, puis la liste pour le reste :

La [burn]torche[/burn] vacille près du feu.

Ce que le joueur voit :

La torche vacille près du feu.
  • L'IA peut ajouter des moments spéciaux.
  • La liste couvre ce qu'elle oublie.

Pour que le jeu reste fluide, seules les dernières lignes bougent ; les anciennes gardent leur couleur. Une option « réduire les effets » coupe toutes les animations.

4. Un tour d'IA, étape par étape

Le jeu garde les règles et lance tous les dés. L'IA raconte et demande des choses par une courte liste de commandes que le jeu vérifie.

  1. Le joueur agit. Il écrit « je traverse le pont » ou clique sur le pont. Le jeu prépare le message pour l'IA : règles, Codex, résumé de l'histoire, état du héros, action.
  2. Attente. Une petite plume s'anime : « Le MJ réfléchit… ». Généralement 2 à 10 secondes.
  3. Réponse. Le jeu sépare le récit des commandes, vérifie chaque commande et jette tout ce qui est inventé.
  4. On joue la scène. Le texte s'écrit avec ses mots animés, puis le héros marche jusqu'au pont, un loup apparaît, la pluie tombe. Un jet demandé ouvre les dés.

Ce que l'IA renvoie (la partie après <<STATE>> est lue par le jeu, pas par le joueur) :

Les planches gémissent quand vous posez le pied sur le pont. En dessous, la rivière file, [freeze]froide[/freeze] et rapide.
Sur l'autre rive, un loup de rouille lève la tête.

6. Connexion à l'IA : trois modes

Copier-coller Gratuit

Le jeu copie le message ; le joueur le colle dans une discussion Claude, puis recolle la réponse dans le jeu. Toujours disponible, même si le reste tombe en panne.

Notre serveur

Le jeu appelle un petit serveur qui garde notre clé secrète et parle à Claude. Le plus simple pour le joueur ; c'est nous qui payons.

Clé du joueur

Le joueur colle sa propre clé dans les réglages ; elle reste sur son appareil. Rien à payer pour nous.
